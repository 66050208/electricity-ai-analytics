# ⚡ Home Electricity AI

เว็บแอป Streamlit สำหรับดูการใช้ไฟและค่าไฟรายเดือนของบ้าน จากข้อมูลบิลจริงของคุณ พร้อมคาดการณ์เดือนหน้า

## ทำอะไรได้
- ล็อกอิน/สมัครสมาชิกด้วย Firebase (Email + Password) และรีเซ็ตรหัสผ่านทางอีเมล
- นำเข้าข้อมูลจริงจาก CSV / Excel (.xlsx) หรือกรอกเอง รองรับเดือนแบบ พ.ศ. (เช่น `ก.ย. 2569`) ตรวจเดือนซ้ำ เดือนที่ขาด และค่าผิดปกติ
- คำนวณค่าไฟตามอัตราก้าวหน้าบ้านอยู่อาศัย (กฟน. รอบบิล ก.ย. 2569) + ค่าบริการ + Ft + VAT หรือใช้ค่าเฉลี่ยต่อหน่วยที่กำหนดเอง
- คาดการณ์เดือนหน้า: ลอง 4 วิธี ทดสอบย้อนหลังกับข้อมูลของคุณเอง แล้วเลือกวิธีที่คลาดเคลื่อนน้อยสุด พร้อมช่วงความไม่แน่นอน
- ดึงอุณหภูมิรายเดือนจาก Open-Meteo (ฟรี ไม่ต้องใช้ key) เพื่อดูความสัมพันธ์กับหน่วยไฟ
- เครื่องคำนวณเครื่องใช้ไฟฟ้า แยกว่าเครื่องไหนกินไฟมากที่สุด
- **📷 อ่านบิลค่าไฟจากรูป/PDF ด้วย AI** (JPG, PNG, WEBP, HEIC, PDF หรือถ่ายจากกล้อง หลายใบพร้อมกัน) ระบบตรวจซ้ำว่าหน่วยตรงกับเลขมิเตอร์และยอดเงินสมเหตุสมผล ให้ผู้ใช้แก้ก่อนบันทึก
- **💬 ถาม AI** แชทถาม-ตอบเรื่องค่าไฟของบ้านคุณ Gemini ทำงานแบบ Agent เรียกเครื่องมือคำนวณจริง (ไม่เดาตัวเลข) และแสดงว่าใช้ข้อมูลอะไรตอบ
- **🔍 วิเคราะห์เชิงลึก** K-Means จัดกลุ่มเดือนเป็น ใช้ไฟต่ำ/ปกติ/สูง บอกรูปแบบบ้าน และ Explainable AI (Random Forest + Permutation Importance) ว่าปัจจัยไหนมีผลต่อการคาดการณ์ พร้อมทดสอบว่าใส่อุณหภูมิแล้วแม่นขึ้นไหม
- **🧮 จำลองและความคุ้มค่า** What-if (จำนวนคน, ทำงานที่บ้าน, ปรับแอร์) และคำนวณระยะคืนทุนการเปลี่ยนเครื่องใช้ไฟฟ้า
- **🌤️ อากาศ 7 วันข้างหน้า** พยากรณ์จาก Open-Meteo + คำแนะนำรายวัน + ประมาณผลต่อการใช้ไฟของบ้านคุณ
- **🏷️ อ่านป้ายเครื่องใช้ไฟฟ้า** ถ่ายป้ายสเปกหรือฉลากเบอร์ 5 ให้ AI เพิ่มเข้าตารางเครื่องใช้ไฟฟ้า
- **📅 ปฏิทินบิล** เก็บวันครบกำหนดจากบิล แจ้งสถานะ และดาวน์โหลด .ics ให้ปฏิทินมือถือเตือนก่อน 2 วัน

## รันในเครื่อง
```bash
pip install -r requirements.txt
cp .env.example .env      # แล้วใส่ FIREBASE_API_KEY
streamlit run app.py
```
ทดลองโดยไม่ต้องมี Firebase: ใส่ `ALLOW_GUEST=1` ใน `.env` จะมีปุ่ม "ลองใช้โดยไม่ล็อกอิน" (ใช้ในเครื่องเท่านั้น)

## ตั้งค่า Gemini (สำหรับอ่านบิลและถาม AI)
1. ขอ API key ฟรีที่ https://aistudio.google.com/apikey
2. ใส่ใน `.env` หรือ Streamlit Secrets:
```toml
GEMINI_API_KEY = "..."
# GEMINI_MODEL = "gemini-3.6-flash"   # ไม่ใส่ก็ได้
```
ถ้าไม่ใส่ key ส่วนอื่นของแอปยังใช้ได้ปกติ เฉพาะ 2 ฟีเจอร์นี้จะแสดงวิธีตั้งค่าแทน

## ทดสอบ
```bash
python tests/test_ai_features.py && python tests/test_new_features.py   # หรือ python -m pytest tests -q
```
ทดสอบเครื่องมือของ AI, การตรวจค่าจากบิล, การรวมข้อมูล และ Agent loop (ใช้ Gemini จำลอง ไม่ต้องมี key)

## ตั้งค่า Firebase
1. Firebase Console → Authentication → Sign-in method → เปิด Email/Password
2. Project settings → Your apps → Web app → คัดลอก Web API key
3. ใส่ใน `.env` (รันในเครื่อง) หรือ Streamlit Secrets (บน Cloud):
```toml
FIREBASE_API_KEY = "..."
```

## รูปแบบไฟล์ข้อมูล
ต้องมีคอลัมน์ **เดือน** และ **หน่วยไฟ (kWh)** ส่วน **ค่าไฟ (บาท)** และ **อุณหภูมิ** ใส่หรือไม่ใส่ก็ได้ ดูตัวอย่างที่ `sample_data/sample_electricity.csv` (ข้อมูลสมมติ) หรือดาวน์โหลดเทมเพลตในหน้า "ข้อมูลค่าไฟ"

ถ้าใส่ค่าไฟจริงอย่างน้อย 3 เดือน ระบบจะปรับค่าไฟที่คาดการณ์ให้ใกล้บิลจริงของคุณ

## หมายเหตุสำคัญ
- อัตราค่าไฟเปลี่ยนได้ทุกงวด ตัวเลขใน `electricity_service.py` อ้างอิงรอบบิล ก.ย. 2569 ของ กฟน. ถ้าอยู่พื้นที่ กฟภ. หรือรอบบิลใหม่ ให้ตรวจและแก้
- ค่าบริการรายเดือน (8.19 / 24.62 บาท) ปรับได้ในแถบตั้งค่า ตรวจให้ตรงกับใบแจ้งค่าไฟของคุณ
- ข้อมูลเก็บในเซสชันเบราว์เซอร์เท่านั้น ไม่ได้บันทึกบนเซิร์ฟเวอร์ ดาวน์โหลดไว้ก่อนออกจากระบบ
- ผลคาดการณ์เป็นการประมาณ ไม่ใช่ยอดบิลจริง
